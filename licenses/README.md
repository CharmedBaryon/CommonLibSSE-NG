# Legacy license

`LICENSE-MIT` is the original MIT license this project was released under before the
move to [GPL-3.0-or-later](../COPYING) (see the [License section](../README.md#license)
of the main README). It's kept here for historical attribution to the original code,
not as the project's current license -- it no longer applies to the project as a whole.

It previously lived at the repository root as a plain `LICENSE` file, which is
ambiguous to GitHub's own license detection and to tooling that scans for a top-level
`LICENSE`/`COPYING` pair: `COPYING` (GPL-3.0-or-later) is this project's actual current
license.
